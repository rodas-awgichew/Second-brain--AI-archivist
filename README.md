 **Second Brain**

Second Brain is web app with Firebase authentication/storage and LLM-powered chat. It offers user sign-up/login, a protected dashboard, file uploads, note/cards UI, and an AI chat assistant via a Gemini service — structured with reusable components, a central auth context, and guarded routes.
## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local)
3. Run the app:
   `npm run dev`
